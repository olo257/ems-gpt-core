# Archiwum dokumentacji

Ten katalog zawiera dokumenty odbiorowe, audyty, handoffy i notatki wydań
historycznych. Zachowano je dla śledzenia decyzji, ale mogą opisywać nieaktualne
encje, wersje i zachowanie.

Nie należy na ich podstawie implementować ani odbierać bieżącej wersji.
Obowiązujące źródła prawdy znajdują się w katalogu głównym dodatku:
`README.md`, `DOCS.md` i `PLANNER_CONTRACT.md`.
